# 🛡️ Unified Attack Management System (UAMS)

## 📋 نظرة عامة
UAMS هو إطار عمل متكامل لأغراض بحثية وتعليمية في مجال أمن المعلومات. 
يسمح النظام ببناء وتوزيع وتحليل نماذج هجمات Android بطريقة آمنة ومحكمة.

## ⚠️ تحذير هام
**هذا النظام للأغراض التعليمية والبحثية فقط.**
- استخدام النظام على أنظمة غير مملوكة لك غير قانوني
- جميع التجارب يجب أن تكون في بيئات معزولة
- أنت المسؤول الوحيد عن استخدامك للنظام

## 🚀 البدء السريع

```bash
# استنساخ المشروع
git clone https://github.com/your-username/UAMS-Framework.git

# تثبيت المتطلبات
